❓ How to Use

Select Regulation

Choose between 21 Regulation or 25 Regulation using the toggle at the top. Each regulation has a different question paper structure.

Enter Paper Details

Fill in the exam type, course code, course name, year, semester, date, and duration. Maximum marks are set automatically from the regulation.

Add Questions

Each section (Part A, B, C) has pre-defined question slots. Type your question text in each slot. Use the rich text editor for formatting.

Set CO (Course Outcome)

Select the Course Outcome (CO1–CO6) for each question from the dropdown. This maps which course outcome the question assesses.

Set Unit

Select which unit (Unit 1–6) the question belongs to. This is used for internal tracking and analysis.

Set K-Level (Bloom's Taxonomy)

K1 – Remember, K2 – Understand, K3 – Apply, K4 – Analyze, K5 – Evaluate, K6 – Create. The system automatically combines CO and K-Level (e.g., CO1-K3).

Add Images (Optional)

Click "+ Add Image" on any question to upload a diagram or figure. You can crop, resize, rotate, and set alignment.

Check Analysis

Go to the Analysis page to see automatic Competency Level Analysis and CO Analysis tables with charts. Everything is calculated from your questions.

Preview Paper

The Preview page shows your question paper exactly as it will appear in the PDF — with college header, tables, analysis, and footer.

Generate PDF

Click "Download PDF" to generate a professional A4 PDF ready for printing. You can also use the browser's Print function.

📖 Glossary

CO (Course Outcome)

Defines what a student should be able to do after completing the course. CO1–CO6 are different outcomes.

K-Level (Bloom's Taxonomy)

K1=Remember, K2=Understand, K3=Apply, K4=Analyze, K5=Evaluate, K6=Create. Measures cognitive complexity.

CO-K Level

Combined notation (e.g., CO1-K3) showing both the course outcome and Bloom's level for a question.

OR Question

Two alternative questions where the student answers only one. Labeled (a) and (b) with "OR" separator.

Competency Analysis

Auto-generated table showing K-level distribution of questions with marks and percentage contribution.

Unit

The syllabus unit (1–6) from which the question is drawn. Used for internal coverage analysis.
